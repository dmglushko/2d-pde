# Prepared assembly implementation and measurements

Starting snapshot: `15bc00d`. Scope: #5 and independent element/edge assembly
numerics from #10. The required `PreparedAssembly` interface and the
`assemble` / `assembly_detail::assemble_impl` entry points are preserved.
`prepared_assembly.hpp` remains the public include; the implementation resides in
`assembly.hpp` so convenience clients use the same preparation and validation.

## Implementation

Preparation owns mesh, problem, options, physical quadrature coordinates/weights,
P1 gradients, edge normals and node mappings. Boundary region assignment and
natural-flux proportionality checks run once. All symbolic restrictions,
differentiation (including reduced Dirichlet derivatives of orders 0/1/2), and
evaluator construction run serially. Shared prepared state is const.

Each time-independent interior coefficient contributes to a cached local block,
even when another coefficient in the same matrix varies with time. Robin matrix,
dynamic-boundary mass and load components are cached separately whenever their
numerator and divisor are time independent. Time dependence is detected
conservatively from free symbols after edge restriction. Time-dependent
coefficients are never sampled at constructor time, so `1/t` can be prepared and
used at positive times. Requested times must still be finite.

Numerical workers borrow evaluator references and write per-element/per-edge
numeric output slots. They construct/copy no Expr or RCP objects. SymEngine
Lambda visitors use their default disabled CSE; numerical calls read functions
without writing intermediate scratch storage. The existing execution helper
selects the lowest failing index and joins workers before rethrowing. Final
constraint checks and sparse/load reduction follow mesh order on the caller
thread. Matrices remain unconstrained. At most nine triplets per element per
matrix and four per natural edge per boundary matrix are emitted, instead of
emitting those counts at every quadrature point. Returned matrices/vectors own
their data.

Strict mesh/assignment/unknown-symbol/nonfinite checks remain. Divisor validation
retains endpoints, midpoint, quadrature samples and sign-change checks; it does
not prove absence of unsampled roots of arbitrary functions. Constant numeric
errors can now be reported by the constructor. Time-dependent boundary data
are validated on each call, including endpoints even when P1 integration uses
interior quadrature. Strong Dirichlet constraints check corner agreement after
edge-local reduction and differentiation.

`statistics()` exposes immutable preparation counts. Interior evaluation counts
exclude boundary evaluations. `interior_evaluations_per_assembly` is the count
for a complete successful call, computed from prepared points and dynamic flags;
failed calls can stop earlier. No mutable diagnostic counters are shared by
workers.

## Reproduction

SymEngine 0.14 static library, AMD Ryzen 9 6900HX, WSL Linux, 16 logical CPUs.
No dependency rebuild, unsafe math flags, or CMake changes.

## Recorded measurements

Before editing, the adapter headers, executable and initial result were saved
under `/tmp/pde2d-assembly-baseline/`; original benchmark source is
`/tmp/assembly-benchmark.cpp`. Initial baseline: preparation 0.00507656 s,
100 assemblies 0.677743 s, checksum 8743. The saved binary was also rerun in the
measurement sequence below. The constant benchmark is identical to that original
benchmark: `square_mesh(20)`, 441 nodes, 800 triangles, 80 edges, degree 2,
`m2=1`, default negative Laplacian and zero flux on all edges, times `i*0.05`.
The variable case additionally sets `c=x+t`, `m1=1+t`, `m2=1+t*t`, and
`source=sin(x+y+t)`.

All prepared runs report 569 prepared evaluators and 2,400 physical quadrature
points. The constant case records 21,600 interior evaluations during preparation,
zero per subsequent assembly, and 5,042 total nonzeros across returned matrices.
The variable case records 12,000 interior evaluations during preparation,
9,600 per assembly, and 8,763 final matrix nonzeros. These evaluator counters
are emitted by the benchmark; nonzeros count the last assembled system.
The saved adapter had no corresponding instrumentation.

These are individual wall-clock samples on shared hardware, with no local builds
running during the measurement sequence; other agents/processes may contend.
No speedup ratio, scaling guarantee, or new end-to-end long-waves timing is
claimed. OpenMP overhead is visible in this small cached constant case. Original
long-waves baseline remains in the audit; this benchmark does not substitute for
a controlled long-waves integration measurement.

## Verification and limits

New tests cover hand-derived mixed diffusion/mass/reaction/source matrices,
caller mutation, manufactured affine solutions with mixed spatial/time
coefficients and dynamic Robin, partial boundary caches, reduced moving
Dirichlet values/velocities/accelerations, and a coefficient undefined at time
zero. Parallel tests require exact serial/2/4-worker results and exercise
threshold/one-worker fallbacks, unavailable backend selection, invalid policy,
interior coefficient errors and boundary divisor errors.

A temporary comparison executable also assembled the saved original implementation
and the new implementation for degree 2/6, three times, and Dirichlet derivative
orders 0/1/2, with mixed spatial/time diffusion, convection, reaction, both masses,
source, moving Dirichlet and dynamic Robin. Maximum absolute matrix/vector norm
difference was `2.08448e-14`. The temporary source/binary are
`/tmp/assembly-differential.cpp` and `/tmp/assembly-differential`; this supplements
the analytical tests and is not an independent FEM-library oracle.

Sparse triplets and output matrices are still rebuilt on each call; cached local
blocks avoid geometry, symbolic and constant integration work, rather than
sharing mutable returned matrices. Edge Dirichlet validation and prescribed
numeric values are evaluated each call. Time-dependent edge ratios that simplify
to constants but still contain `t` conservatively remain dynamic. No sanitizer
run or external scikit-fem/SciPy comparison was performed by this assembly-only
agent; the independent-reference portion of #10 belongs to the separate owner.

Final focused serial-only validation passed 4/4 tests, including existing
`fem_transient` compatibility coverage. OpenMP validation passed 3/3 focused
assembly tests, with OpenMP available and the 2/4-worker branches executed.
`git diff --check` passed. Build warnings came from the existing SymEngine
package's C++23 compatibility headers.

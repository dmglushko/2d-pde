## Recorded baseline

`docs/fem/long-waves-timings.json` is a single recorded Release run on 441
vertices / 800 triangles, `dt=0.05`, 100 seconds per case. It is not a controlled
multi-run benchmark. Its grouped costs are:

| Wall seconds | Driven Dirichlet | Free Neumann |
| --- | ---: | ---: |
| Integration | 41.580 | 42.085 |
| Assembly (includes validation and preparation) | 27.994 | 21.486 |
| QR rank checks | 11.980 | 18.928 |
| LU factorization | 1.200 | 1.384 |
| Applying LU factors | 0.0406 | 0.0436 |
| Postprocessing diagnostics | 0.0085 | 7.526 |

No claim is made about which assembly subphase dominates: it was not separately
instrumented. Implementation agents must save baseline binaries/results before
editing and compare like-for-like settings. Integration verification will
record compiler, CPU, thread count, mesh size, settings, operation counts and
actual errors. Performance experiments must not become flaky timing thresholds
in correctness tests.

## Concurrency boundaries and invariants

- Serial remains the default and a dependency-light build remains supported.
- Independent element/edge numerical work, validation candidates and diagnostic
  elements may run concurrently. Compute local results and combine in stable
  order. Preserve robust exact fallback predicates and deterministic ties.
- Prepare symbolic expressions and evaluator ownership serially; concurrent
  SymEngine RCP copying/mutation is not assumed safe.
- Time steps depend on previous states. Topology edits and geometry edits remain
  ordered; do not parallelize them speculatively. Avoid nested thread pools.
- Public input validation is not weakened. Prepared objects own immutable input
  snapshots; a caller's later edits cannot invalidate hidden cache assumptions.
- Keep current mesh formats, P1 connectivity, curve identity/replay semantics,
  boundary source coverage, unsupported-class errors and compatibility wrappers.

## Areas with no separate optimization issue

Filtered/exact predicate fallbacks are deliberate correctness mechanisms, not
removable overhead. Strict I/O/provenance and SVG endpoint/ambiguity validation
remain necessary; only duplicated passes and candidate enumeration are targeted.
Small formatting/allocation changes without material evidence are not tickets.
Reference docs and generated artifacts do not execute in the numerical kernel.
